邏輯斯迴歸

講義 L04 p.1–25 課本 Ch.4 p.89–112（含 §3.2） 資料 Horseshoe Crabs、AZT
這講在解決什麼問題
L02 兩個類別變數有沒有關聯→ L03 GLM：把迴歸推廣到非常態的 Y→ L04 GLM 用在二元 Y→ L05 模型好不好、怎麼選變數

L02 的列聯表一次只能看一兩個類別型 X，也放不進「殼寬 26.3 公分」這種連續變數。這講要回答的是：Y 只有 0/1 兩種結果時，怎麼讓好幾個 X（連續或類別都行）一起預測 P(Y=1)？

答案是 logistic regression，也就是 L03 學過的 GLM 選定兩個零件：隨機成分用二項分配，連結函數用 logit。整講可以濃縮成三件事：為什麼是 logit、β 怎麼翻譯成人話、怎麼檢定一個變數（或一組 dummy）該不該留在模型裡。

逐頁筆記

p.1–21.1 The Logistic Regression Model
4-1

為什麼不用直線，而要取 logit？

講義 p.1–2, 6課本 §3.2.1 p.68、§4.1 p.89–91
為什麼要這樣做

最直覺的做法是直接用一般迴歸，令 π(x) = α + βx，這叫 linear probability model（LPM）。講義 p.2 列了它的三個問題：

  1. 會超出 0–1：鱟的例子用 LPM，最寬的 33.5 公分會算出機率 1.3（p.6）。
  2. 變異數不固定：Var(Y|x) = π(1−π) 隨 x 改變，OLS 的標準誤因此不可靠。
  3. 真實關係不是直線：機率靠近 0 或 1 時應該變化得越來越慢。

機率被關在 0 到 1 的房間裡，直線遲早會撞牆。先換成 odds = π/(1−π)，天花板就打開了，範圍變成 0 到 ∞。再取 log，地板也打開了，範圍變成 −∞ 到 ∞。這時候用直線去配就不會撞牆，最後換回機率，自然就是一條 S 形曲線。

logit[π(x)] = log π(x)1 − π(x) = α + βx  ⇔  π(x) = exp(α + βx)1 + exp(α + βx) 左式是 log-odds 尺度上的直線，右式是機率尺度上的 S 形曲線。兩邊是同一個模型，只是換了尺度。
什麼時候用
  • Y 是二元的（有／無、成功／失敗），想知道 X 怎麼影響 P(Y=1)。
  • Probit 模型（講義 p.2 下半）把 logit 換成 Φ⁻¹，曲線形狀幾乎一樣。課堂預設用 logit，因為 eβ 可以直接解讀成 odds ratio。
  • LPM 只在機率都落在 0.2–0.8、不外插時勉強可用。
p.3–41.2 Interpreting the Logistic Model ・ 1.3 Inference
4-2

β 怎麼翻譯成人話：odds ratio 與斜率

講義 p.3–4課本 p.90–91、Fig 4.1
為什麼要這樣做

β 的單位是「log-odds 增加多少」，沒有人會這樣說話。講義 p.3 給了兩種翻譯：

  • Odds ratio（給統計人）：x 增加 1，odds 乘上 eβ。不論從哪個 x 開始，倍數都一樣。
  • 斜率（給非統計人）：x 增加 1，機率大約增加 βπ(x)[1−π(x)]。這個量會隨 x 改變，在 π = 0.5 時最大，等於 β/4。

S 形曲線像一座山坡：山腳和山頂幾乎是平地，半山腰（π = 0.5）最陡。機率的變化就是「高度變化」，要看你站在哪裡。odds 則像複利，每走一步都乘上同一個倍數 eβ，不管站在哪裡。

odds(x+1) / odds(x) = eβ ｜ dπ/dx = βπ(x)[1 − π(x)] ｜ EL50 = −α/β EL50 是 π = 0.5 時的 x，也是曲線最陡的地方（p.4 上方）。

拖動殼寬：「odds 比值」一直等於 eβ，但「斜率」一直在變。這就是兩種解讀的差別。

常見陷阱
  • eβ 不是「機率的倍數」，是 odds 的倍數。機率最大是 1，不可能一直乘下去。
  • β/4 是斜率的上限，只在 π = 0.5 附近成立。
4-3

對 β 做推論：Wald 和 LR

講義 p.4課本 §4.2 p.94–96
為什麼要這樣做

β̂ 是從一批樣本估出來的，換一批就會不同。推論要回答兩件事：β 的合理範圍在哪裡（CI），以及有沒有證據說 β ≠ 0（檢定）。兩件事都有 Wald 和 likelihood-ratio（LR）兩種做法，這是 L01 比例推論的延伸。

Wald 只站在山頂（β̂），看山頂附近的坡度（SE）來猜整座山的形狀。LR 則真的走下去，比較「山頂的高度」和「β = 0 那個位置的高度」差多少。山形對稱時兩者一樣；山形歪斜時，要相信 LR。

Wald：z = β̂ / SE，CI 為 β̂ ± zα/2·SE
LR：2(L₁ − L₀) = Deviance₀ − Deviance₁ ~ χ²(df) L₀、L₁ 是 H₀ 模型與完整模型的最大化 log-likelihood；df 是兩個模型的參數個數差。
學派與爭議

Wald 和 LR 該信哪個？講義 p.4 的立場很明確：n 小、或配適機率大多貼近 0 或 1 時，LR 比 Wald 更有檢定力，也更可靠。Wald 的優點只是好算，軟體每一列直接印給你。課本也一直優先報 LR。極端情況下 Wald 甚至會失效，這會在 L05 的「稀疏資料」再出現。

p.5–81.3.2 CI for Probabilities ・ 1.4 Horseshoe Crabs Example
4-4

π(x) 的信賴區間：先在 logit 尺度算，再轉回來

講義 p.4–5課本 §4.2.3 p.96–97
為什麼要這樣做

直接在機率尺度上用 π̂ ± 1.96·SE，端點可能跑出 0–1。所以先對線性預測值 α̂ + β̂x 建 CI（它的範圍是整條實數線，常態近似比較合理），再把兩個端點丟進 logistic 函數換回機率。這跟 4-1「先換尺度再用直線」是同一個想法。

α̂ + β̂x 的變異數要用到共變異數：Var(α̂) + x²Var(β̂) + 2x·Cov(α̂, β̂)。講義 p.5 的空白處就是要你寫這條式子。

什麼時候用

想回答「殼寬 26.5 公分的鱟，有跟班的機率是多少、估得多準」時使用。R 的做法見 4-6。

類別型 X：dummy 變數與參考組

講義 p.11–14課本 §4.4 p.102–104、Fig 4.4
為什麼要這樣做

顏色編成 1、2、3、4 只是標籤，「深色 = 4 倍的淺色」沒有意義。所以 c 個類別要拆成 c − 1 個 0/1 的 dummy，剩下那一組全部是 0，當作參考組。每個 dummy 的係數都在回答「這一組跟參考組比差多少」。

像匯率都以美元報價：日圓、歐元、台幣各有一個「對美元」的數字，美元自己不用報。換成以歐元報價，數字全變了，但各國貨幣的相對價值不變。

logit[P̂(Y=1)] = −12.715 + 1.330c₁ + 1.402c₂ + 1.106c₃ + 0.468x c₁、c₂、c₃ = medium light、medium、medium dark；dark 是參考組（p.12）。
  • e1.330 = 3.8：在相同殼寬下，medium light 的 odds 是 dark 的 3.8 倍（p.13）。
  • 非參考組之間也能比：係數相減再取 exp，例如 e1.402 − 1.330。
  • 沒有交互作用項，所以四條曲線形狀相同、只是左右平移，永遠不會交叉（p.12）。
R · 把顏色變成 factor 並指定參考組（p.13）
Crabs$newcolor <- factor(Crabs$color)
Crabs$newcolor <- relevel(Crabs$newcolor, ref = "4")   # dark 當參考組
fit2 <- glm(y ~ width + newcolor, family = binomial, data = Crabs)
R 輸出怎麼讀

summary(fit2) 裡 newcolor1 那一列（1.3299，p = 0.12）是「medium light 對 dark」，不是「顏色整體」。要檢定顏色整體，看 4-8。

常見陷阱

沒有轉成 factor 的話，R 會把 color 當成連續的 1–4，模型就變成 4-8 的「有序分數」模型。轉換前先用 is.factor() 檢查。

p.17–191.5.3 Interaction
4-9

交互作用：殼寬的效果會因顏色而不同嗎？

講義 p.17–19課本 p.106
為什麼要這樣做

4-7 的模型假設殼寬效果在每種顏色都一樣（曲線平行）。加上 c × x 之後，每種顏色有自己的斜率，就可以檢查這個假設。

logit[P̂(Y=1)] = −12.812 + 6.958c + 0.522x − 0.322(c × x) dark：−5.854 + 0.200x；較淺色：−12.812 + 0.522x；兩條曲線在 x = 21.6 交叉（p.17）。

LR = 187.96 − 186.79 = 1.17，df = 1，p = 0.28，交互作用證據不足。樣本斜率差很多，但 dark 只有 22 隻，標準誤很大。沒有交互作用的模型比較好解釋，所以保留簡單模型（p.18）。

常見陷阱

有交互作用項時，dark 的係數 6.958 是「殼寬 = 0 時」的差異，沒有實際意義。不能單獨解讀主效果，要分組寫出各自的方程式。

4-10

Marginal effect：用「機率」摘要效果

講義 p.19–20課本 §4.5 p.107–109
為什麼要這樣做

4-2 說斜率 βπ(1−π) 會隨 x 改變，那要報哪一個？折衷做法是把每一隻鱟的斜率都算出來再取平均，叫 average marginal effect（AME）。二元變數則把每隻鱟分別設成 dark = 1 和 0，取機率差的平均，叫 discrete change。

  • width 的 AME = 0.087：平均而言，殼寬每多 1 公分，機率約增加 0.087。
  • dark 的 discrete change = −0.26：同樣的殼寬下，dark 的機率平均少 0.26。
R · 手動算 AME（講義另用 mfx、margins 套件）
p <- predict(fit, type = "response")
mean(coef(fit)["width"] * p * (1 - p))     # 0.0875
什麼時候用

要對非統計背景的人說「平均而言機率變多少」時用。odds ratio 適合跨研究比較，AME 適合說明實際影響有多大。

2×2×K 表的 logit 模型：接回 L02

講義 p.21–22課本 §4.3 p.98–101、Ex.4.10 p.116
為什麼要這樣做

L02 處理三維表用的是 CMH 和 Breslow-Day 檢定。這裡說明它們都能改寫成 logistic 模型 logit[P(Y=1)] = α + βx + βkZ，其中 eβ 就是「每一層 Z 共同的 XY odds ratio」。

問題L02 的工具L04 的對應
控制 Z 後，X 與 Y 獨立嗎？CMH 檢定H₀: β = 0（Wald 或 LR）
各層 odds ratio 相同嗎？Breslow-Day模型 goodness of fit（L05）

AZT 的例子：e−0.720 = 0.49。不論是哪個種族，立即使用 AZT 的人出現症狀的 odds 約只有一半（p.22）。

p.23–251.8 Summarizing Predictive Power
4-12

預測力：分類表、ROC 與 AUC

講義 p.22–25課本 §4.6 p.110–112
為什麼要這樣做

前面都在問「X 跟 Y 有沒有關係」，這裡換一個問題：拿模型來猜每隻鱟有沒有跟班，猜得準不準？做法是設門檻 π₀，π̂ > π₀ 就猜 1。但門檻是人選的，所以 ROC 把所有門檻都畫出來，曲線下面積（AUC，又叫 c-index）就是不依賴門檻的總分。

像機場安檢的敏感度旋鈕：轉得越敏感，抓到越多危險物品（sensitivity ↑），誤攔的旅客也越多（specificity ↓）。ROC 就是把旋鈕從頭轉到尾，記錄下這個取捨。

模型AUC解讀
只有 color0.639比亂猜（0.5）好一點
只有 width0.742殼寬是主要的預測來源
width + color0.771加上顏色有小幅提升

以 π₀ = 0.6416（樣本中 y=1 的比例）分類：sensitivity = 75/111 = 0.68，specificity = 43/62 = 0.69（p.23）。

常見陷阱
  • 顏色「略有證據」（4-8，p = 0.07），AUC 也只從 0.742 升到 0.771。「顯不顯著」和「預測提升多少」是兩個不同的問題。
  • plot.roc() 要加 legacy.axes = TRUE，x 軸才是 1 − specificity，跟課本的圖一致。

自我檢查

Q1. 有人說「β̂ = 0.497，所以殼寬每多 1 公分，有跟班的機率增加 49.7%」，錯在哪？

兩個錯誤。β 是 log-odds 的變化，不是機率的變化；就算取 eβ = 1.64，也是 odds 增加 64%，不是機率。機率的變化要用 βπ(1−π)，而且要指定在哪個 x 附近（見 4-2）。

Q2. 為什麼 π(x) 的信賴區間不直接用 π̂ ± 1.96·SE？

端點可能超出 0–1，而且機率尺度上的抽樣分配不對稱。要先在 logit 尺度建 CI，再轉回機率（見 4-4）。

Q3. 三個顏色 dummy 的 p 值分別是 0.12、0.01、0.06，可以說「顏色有顯著影響」嗎？

不能直接這樣說。三個 p 值各自比的是「某一色對 dark」。檢定顏色整體要用 LR 比較有無顏色的模型：6.99，df = 3，p = 0.07，只能算略有證據（見 4-8）。

Q4. 什麼情況下特別該用 LR 而不是 Wald？

樣本小，或配適機率大多貼近 0 或 1 時。這時 log-likelihood 不對稱，Wald 的常態近似不可靠（見 4-3）。
